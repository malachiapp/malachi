Which file do I need?

There is a separate, smaller file for each processor type. Almost all phones from about 2017 onwards need "arm64-v8a". If the file won't install ("App not installed"), take "armeabi-v7a" (older 32-bit devices). "x86_64" is only for emulators and some Chromebooks.

Verify the file

This is how you make sure the file is complete and really comes from Malachi. To be safest, also compare the values over a second route, for example once via the normal address and once via the onion address.

1. Compare the checksum (SHA-256)

The output must match the value in the table above exactly. Upper and lower case don't matter.

  • Linux: sha256sum {{APK_HAUPT_DATEI}}
  • macOS: shasum -a 256 {{APK_HAUPT_DATEI}}
  • Windows (Command Prompt): certutil -hashfile {{APK_HAUPT_DATEI}} SHA256
  • Windows (PowerShell): Get-FileHash .\{{APK_HAUPT_DATEI}} -Algorithm SHA256

All checksums are also listed in the file SHA256SUMS. On Linux, sha256sum -c --ignore-missing SHA256SUMS checks all downloaded files at once.

2. Compare the signing certificate

Every Malachi APK is signed with the same key. Its certificate has this SHA-256 fingerprint:

{{APK_ZERTIFIKAT_SHA256}}

With apksigner from the Android SDK Build-Tools (on Windows apksigner.bat):

apksigner verify --print-certs {{APK_HAUPT_DATEI}}

The line Signer #1 certificate SHA-256 digest: must show exactly the value above. keytool -printcert -jarfile {{APK_HAUPT_DATEI}} shows the same value written with colons:

{{APK_ZERTIFIKAT_SHA256_DOPPELPUNKT}}

3. Advanced: signed version list

The file updates/manifest.json lists version, size and SHA-256 of every file. It is signed with an Ed25519 key that is never stored on this server (manifest.json.sig, Base64). The public key is {{UPDATE_SCHLUESSEL}} (Base64url, 32 bytes; as a file: update-schluessel.pem). Verify with OpenSSL 3:

base64 -d manifest.json.sig > manifest.sig.bin
openssl pkeyutl -verify -pubin -inkey update-schluessel.pem -rawin -in manifest.json -sigfile manifest.sig.bin

Expected output: Signature Verified Successfully. Then compare the SHA-256 of the APK with the value in manifest.json.

Build it yourself

The source code is public on GitHub (AGPL-3.0 license); build instructions are in the README. An app you build yourself is signed with your own key – so Android won't install it as an update over the official version, and vice versa.

Install

  1. Download the APK on your phone (in the browser or in Tor Browser for Android).
  2. Open the file. Android asks whether the app you open it with (browser or file manager) may "install unknown apps". Allow this for that one app only.
  3. Tap "Install".
  4. Afterwards, revoke the permission from step 2 in the Android settings.

Updates: You simply install a new version over the old one; your chats are kept. Android only accepts an update if it is signed with the same key as the installed app. A fake APK with a different key therefore cannot replace your installed Malachi – Android stops with an error message. In that case, don't install anything; download the file from here again.
