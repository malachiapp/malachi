Welche Datei brauche ich?

Für jeden Prozessortyp gibt es eine eigene, kleinere Datei. Fast alle Handys ab etwa 2017 brauchen „arm64-v8a“. Lässt sich die Datei nicht installieren („App nicht installiert“), nimm „armeabi-v7a“ (ältere 32-Bit-Geräte). „x86_64“ ist nur für Emulatoren und manche Chromebooks.

Datei prüfen

So stellst du sicher, dass die Datei vollständig ist und wirklich von Malachi stammt. Am sichersten vergleichst du die Werte zusätzlich über einen zweiten Weg, zum Beispiel einmal über die normale Adresse und einmal über die Onion-Adresse.

1. Prüfsumme (SHA-256) vergleichen

Die Ausgabe muss genau dem Wert in der Tabelle oben entsprechen. Groß- und Kleinschreibung spielt keine Rolle.

  • Linux: sha256sum {{APK_HAUPT_DATEI}}
  • macOS: shasum -a 256 {{APK_HAUPT_DATEI}}
  • Windows (Eingabeaufforderung): certutil -hashfile {{APK_HAUPT_DATEI}} SHA256
  • Windows (PowerShell): Get-FileHash .\{{APK_HAUPT_DATEI}} -Algorithm SHA256

Alle Prüfsummen stehen auch in der Datei SHA256SUMS. Unter Linux prüft sha256sum -c --ignore-missing SHA256SUMS alle heruntergeladenen Dateien auf einmal.

2. Signaturzertifikat vergleichen

Jede Malachi-APK ist mit demselben Schlüssel signiert. Sein Zertifikat hat diesen SHA-256-Fingerabdruck:

{{APK_ZERTIFIKAT_SHA256}}

Mit apksigner aus den Android SDK Build-Tools (unter Windows apksigner.bat):

apksigner verify --print-certs {{APK_HAUPT_DATEI}}

Die Zeile Signer #1 certificate SHA-256 digest: muss genau den Wert oben zeigen. keytool -printcert -jarfile {{APK_HAUPT_DATEI}} zeigt denselben Wert in der Schreibweise mit Doppelpunkten:

{{APK_ZERTIFIKAT_SHA256_DOPPELPUNKT}}

3. Für Fortgeschrittene: signierte Versionsliste

Die Datei updates/manifest.json nennt Version, Größe und SHA-256 jeder Datei. Sie ist mit einem Ed25519-Schlüssel signiert, der nie auf diesem Server liegt (manifest.json.sig, Base64). Der öffentliche Schlüssel lautet {{UPDATE_SCHLUESSEL}} (Base64url, 32 Byte; als Datei: update-schluessel.pem). Prüfen mit OpenSSL 3:

base64 -d manifest.json.sig > manifest.sig.bin
openssl pkeyutl -verify -pubin -inkey update-schluessel.pem -rawin -in manifest.json -sigfile manifest.sig.bin

Erwartete Ausgabe: Signature Verified Successfully. Danach die SHA-256 der APK mit dem Wert in manifest.json vergleichen.

Installieren

  1. Die APK auf dem Handy herunterladen (im Browser oder im Tor-Browser für Android).
  2. Die Datei öffnen. Android fragt, ob die App, mit der du sie öffnest (Browser oder Dateimanager), „unbekannte Apps installieren“ darf. Erlaube das nur für diese eine App.
  3. „Installieren“ tippen.
  4. Danach die Erlaubnis aus Schritt 2 in den Android-Einstellungen wieder entziehen.

Updates: Eine neue Version installierst du einfach über die alte; deine Chats bleiben erhalten. Android nimmt ein Update nur an, wenn es mit demselben Schlüssel signiert ist wie die installierte App. Eine gefälschte APK mit anderem Schlüssel kann dein installiertes Malachi deshalb nicht ersetzen – Android bricht dann mit einer Fehlermeldung ab. Installiere in diesem Fall nichts, sondern lade die Datei hier neu.
